# Agência de Viagens

Site de agência de viagens com apresentação de ofertas e formulário para solicitação de orçamento.

**Demo:** https://rogerrochago02.github.io/Agencia/

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — estrutura, ofertas e formulário
- `style.css` — estilos e layout

## Como executar

```bash
git clone https://github.com/rogerrochago02/Agencia.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
